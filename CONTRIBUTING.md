# Katkı rehberi

1. Bir değişiklik yapmadan önce bir GitHub Issue açın veya mevcut Issue'yu kullanın.
2. Değişikliğinizi küçük ve açıklayıcı bir dalda geliştirin.
3. Kullanıcıya görünen değişiklikleri README ve CHANGELOG içinde açıklayın.
4. Pull request açıklamasında değişikliği, işletim sistemini ve doğrulama adımlarını belirtin.
5. Yeni bağımlılık eklemeden önce gerekçesini ve lisansını belirtin.

Depo için genel bir açık kaynak lisansı seçilene kadar katkıların kullanım koşullarını proje sahibiyle netleştirin.
